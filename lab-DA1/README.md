# House Price Prediction using Machine Learning

## Project Overview

This project implements multiple regression models to predict house prices. The script performs data preprocessing, exploratory data analysis (EDA), model training, evaluation, hyperparameter tuning, and model comparison.

## Requirements

- Python 3.10 or later
- pip

## Files Required

- `pred-labDA1-all.py`
- `requirements.txt`

## Installation

Install the required Python packages:

```bash
pip install -r requirements.txt
```

## Running the Project

Run the Python script:

```bash
python pred-labDA1-all.py
```

## Output

After running the script, you will be able to view:

- Dataset information
- Exploratory Data Analysis (EDA)
- Data visualizations and plots
- Model training results
- Evaluation metrics (MAE, MSE, RMSE, R² Score)
- Cross-validation scores
- Hyperparameter tuning results
- Model comparison
- Saved machine learning model (Joblib)

## Algorithms Used

- Linear Regression
- Polynomial Regression
- Decision Tree Regressor
- Random Forest Regressor
- Dummy Regressor (Baseline)

## Evaluation Metrics

- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- Root Mean Squared Error (RMSE)
- R² Score
- Cross Validation
